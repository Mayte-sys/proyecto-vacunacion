# Proyecto de Vacunación

Sistema desarrollado en Java para la gestión de campañas de vacunación.

## Módulos
- App Ciudadanos
- Sector Salud

## Funcionalidades
- Registro de ciudadanos
- Gestión de campañas de vacunación
- Asignación de vacunas
- Consulta de cartillas
- Administración de datos

## Tecnologías
- Java
- Swing
- MySQL
- NetBeans

# Base de Datos
Para instalar la base de datos:

1. Crear la base de datos SectorSalud.
2. Ejecutar el script `SectorSalud.sql`.
3. Configurar las credenciales en `Conexion_DB.java`.
